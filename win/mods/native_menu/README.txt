Native Menu v0.1 (Modernization Core)

The game's main menu (Tab) lists Item, Weapon, Allies, Georama Parts, Go to Dungeon, Save, Option and now MODS in the slot the Manuals used to have.
Its art is the game's own menu sheet (textures/stayframe.png, the MANUALS label redrawn as MODS). Choosing MODS opens one list of every mod page
(Skill Tree, Controls, Bestiary, Trophies, Co-op, ...). The last row, "Manuals (how to play)", opens the original manuals.

To restore the original menu art, turn this mod off in mod_manager.py.
